# Codex Project Colors · Codex 项目配色

macOS 上的 Codex 项目配色与账号额度辅助程序，版本 1.0.0，发布标签 `v1.0.0-balance-icon`。本项目是社区工具，不代表 OpenAI 官方发布或支持。

## 一次安装后的使用

从 [Releases](https://github.com/AnFeng-rgb/Codex-Project-Colors/releases) 下载 `CodexProjectColors-v1.0.0-balance-icon-macos-arm64.zip`。程序内置 Node.js 24.21.0，不需要普通使用者另装运行环境。源码下载包需按下方“开发”说明构建程序。解压程序包，双击 Codex Project Colors.app，点击“安装并启用”，阅读并接受启动行为说明。

程序会复制到个人“应用程序”目录，配色独立保存在 `~/Library/Application Support/CodexProjectColors`，并注册用户级登录助手。安装成功后仍使用原官方图标，管理窗口可以关闭，原解压包不再是运行依赖。

**自动接入方式：对刚启动、前台且尚未操作的官方应用，正常退出并带本机连接参数重开一次。** 普通启动窗口限八秒。开机两分钟内，若官方应用先于登录助手启动，只对启动不超过三十秒、前台且全程未操作的实例补做接入；已有工作窗口、发生过输入、背景启动、端口占用、多个实例、退出拒绝或超时均跳过。退出期间发生输入也会取消重开。不会强制结束应用，不修改官方应用包或 Dock 图标。该限制是为了保留用户工作；不承诺在所有启动情形或未来客户端版本中无条件接入。

首次安装默认开启上色，识别到本地项目后自动分配并保存一套六色方案，无需先手动选色。之后在官方应用头像上方打开调色盘，可修改单个项目颜色或点击“全部项目随机配色”更换方案。六种默认颜色内置红、橙、黄、绿、蓝、紫及深浅主题显示值；项目 ID 对应的私人配色不随程序分发。

## 配色功能

- 首次自动生成并保存方案；已有配色保留，重连沿用原方案，用户主动清空后不自动补回。
- 单行六色圆点，选中色细圈与勾号；色轮收进“自定义”。
- 项目彩色图标与宽月牙；选中对话同色文字和圆角竖条，无底纹。
- 项目列表勾选状态、长名称悬停及深浅模式。
- 恢复默认、全部本地项目随机配色与 30 秒一次撤销。
- 独立保存、校验、原子写入及上一版备份。
- 安装、停用、重新启用、选择连接窗口、选择官方应用和卸载。

## 1.0 新增余额 / 额度功能

- 侧边栏同一张窄卡片包含额度和调色盘两个独立按钮，无分隔横线，各自有悬浮底色；额度按钮显示同尺寸的剩余额度圆环，按实际数据显示五小时加周额度或仅周额度。
- 点击打开宽度最多 200px 的详情，显示额度重置时间、可用重置卡张数和单行到期时间；界面沿用“充值卡”名称，对应接口中的额度重置卡，不将充值余额换算成卡券。
- 三天内到期的可用卡优先显示，日期和“即将到期”为红色；收起时有独立红色“!”及悬停数量提示，不改变额度圆环颜色。
- 配色面板底部有独立“显示账号额度”开关，关闭后仍保留调色盘入口，状态在重连后保留；隐藏时停止额度读取。
- 仅显示五小时加周额度或仅周额度，不加倒计时、系统通知和手动刷新按钮；正常读数不增加常驻状态说明。
- 通过官方安装包内的 Codex app-server 的 `account/rateLimits/read` 只读获取，每分钟更新；不创建聊天或兑换卡券。
- 无数据显示未知，读取失败标记上次读数；不保存账户凭据或卡券 ID。
- 此处“余额”指账号剩余额度，不代表现金余额或月额度。额度读取失败时保留并标明上次读数，未知卡券信息不会补造。

## 安装与卸载

见 [安装说明](INSTALL.md)。停用自动配色会注销本工具的登录助手并停止后台；卸载还会移除已安装的本工具程序，保留配色与备份。不退出官方应用，不删除用户聊天，也不修改其他登录项目。

## 兼容与验收

当前包为 Apple Silicon。验证基准为 macOS 27.0、ChatGPT 26.1007.30912 的 Codex 界面。默认目标为该官方应用，可在管理窗口“更多操作”选择安装路径；其他客户端界面结构可能需要适配。Intel 与 Windows 尚未验收。

65 项 Node 检查、38 项隔离浏览器界面检查及本机开关保存和后台重连检查通过。原官方图标普通冷启动、清空重装和首次配色已在本机实测；新增开机先后顺序保护已通过自动检查，整机重启后的专项实测仍待完成。其他机器兼容性尚未验证。

当前包有本地完整性签名，**没有 Developer ID 签名和 Apple 公证**。公开下载后可能被 macOS 阻止；面向普通用户的顺畅安装仍需对应开发者证书及公证。请按本页的实测范围评估兼容性。

## 开发

Node.js 24+，macOS 构建另需 Xcode Command Line Tools。

```sh
npm test
npm run build:macos
```

构建脚本从 Node 官方下载固定版本并核对 SHA256，随后内置二进制和许可，输出 `release/颜色标签.app`。不会在构建时安装登录后台或退出官方应用。

开发者签名和公证流程已准备在 `src/macos/sign-release.mjs`。运行前须具备 Developer ID Application 证书和已保存的钥匙串公证配置，分别通过 `COLOR_LABELS_SIGN_IDENTITY` 与 `COLOR_LABELS_NOTARY_PROFILE` 指定。该脚本会向 Apple 提交程序；应由发布者明确确认后运行。缺少配置或证书时会在修改和上传前停止。公证后需重新打包，不能使用之前的未公证 ZIP；目前此流程尚未完成真实证书验收。

`src/` 为后台、安装与持久化；`src/startup/` 和 `src/macos/StartupBridge.m` 为启动观察；`demo/core/` 是共享的界面、身份与 CDP 模块。测试和程序构建不依赖业务项目数据。

额度界面有可选的无头浏览器检查，默认使用虚构数据、不读取账号，见 [界面检查说明](verification/quota/README.md)。
