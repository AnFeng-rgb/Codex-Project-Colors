# Codex Project Colors · Codex 项目配色

macOS 上的 Codex 项目配色辅助程序，版本 0.2.0。本项目是社区工具，不代表 OpenAI 官方发布或支持。

## 一次安装后的使用

程序候选包内置 Node.js 24.21.0，不需要普通使用者另装运行环境。源码下载包需按下方“开发”说明构建程序。解压程序包，双击 Codex Project Colors.app，点击“安装并启用”，阅读并接受启动行为说明。

程序会复制到个人“应用程序”目录，配色独立保存在 `~/Library/Application Support/CodexProjectColors`，并注册用户级登录助手。安装成功后仍使用原官方图标，管理窗口可以关闭，原解压包不再是运行依赖。

**自动接入方式：对刚启动、前台且尚未操作的官方应用，正常退出并带本机连接参数重开一次。** 启动窗口限八秒；已有工作窗口、发生过输入、背景启动、端口占用、多个实例、退出拒绝或超时均跳过。退出期间发生输入也会取消重开。不会强制结束应用，不修改官方应用包或 Dock 图标。该限制是为了保留用户工作；不承诺在所有启动情形或未来客户端版本中无条件接入。

首次安装默认开启上色，识别到本地项目后自动分配并保存一套六色方案，无需先手动选色。之后在官方应用头像上方打开调色盘，可修改单个项目颜色或点击“全部项目随机配色”更换方案。六种默认颜色内置红、橙、黄、绿、蓝、紫及深浅主题显示值；项目 ID 对应的私人配色不随程序分发。

## 配色功能

- 首次自动生成并保存方案；已有配色保留，重连沿用原方案，用户主动清空后不自动补回。
- 单行六色圆点，选中色细圈与勾号；色轮收进“自定义”。
- 项目彩色图标与宽月牙；选中对话同色文字和圆角竖条，无底纹。
- 项目列表勾选状态、长名称悬停及深浅模式。
- 恢复默认、全部本地项目随机配色与 30 秒一次撤销。
- 独立保存、校验、原子写入及上一版备份。
- 安装、停用、重新启用、选择连接窗口、选择官方应用和卸载。

## 安装与卸载

见 [安装说明](INSTALL.md)。停用自动配色会注销本工具的登录助手并停止后台；卸载还会移除已安装的本工具程序，保留配色与备份。不退出官方应用，不删除用户聊天，也不修改其他登录项目。

安装和启动策略单元检查、内置运行环境以及真实原生观察助手的启动/停止检查已通过。原官方图标冷启动已在开发者本机实际通过：启动助手记录正常重开、后台自动连接、配色开启且原配色保留。本机清空数据后的安装、保存、卸载及重新安装已通过；其他机器兼容性尚未验证。当前版本定位为 0.2.0 预发布。

当前包有本地完整性签名，**没有 Developer ID 签名和 Apple 公证**。公开下载后可能被 macOS 阻止；面向普通用户的顺畅安装仍需对应开发者证书及公证。请按本页的实测范围评估兼容性。

## 开发

Node.js 24+，macOS 构建另需 Xcode Command Line Tools。

```sh
npm test
npm run build:macos
```

构建脚本从 Node 官方下载固定版本并核对 SHA256，随后内置二进制和许可，输出 `release/颜色标签.app`。不会在构建时安装登录后台或退出官方应用。

开发者签名和公证流程已准备在 `src/macos/sign-release.mjs`。运行前须具备 Developer ID Application 证书和已保存的钥匙串公证配置，分别通过 `COLOR_LABELS_SIGN_IDENTITY` 与 `COLOR_LABELS_NOTARY_PROFILE` 指定。该脚本会向 Apple 提交程序；应由发布者明确确认后运行。缺少配置或证书时会在修改和上传前停止。公证后需重新打包，不能使用之前的未公证 ZIP；目前此流程尚未完成真实证书验收。

`src/` 为后台、安装与持久化；`src/startup/` 和 `src/macos/StartupBridge.m` 为启动观察；`demo/core/` 是共享的界面、身份与 CDP 模块。测试和程序构建不依赖业务项目数据。
