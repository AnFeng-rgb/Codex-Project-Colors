# Codex 项目配色 1.0 · 安装说明

1. 解压程序包，双击 Codex Project Colors.app。无需另装 Node。
2. 点击“安装并启用”，阅读提示并确认：登录后台观察官方图标启动；对刚启动、前台且未操作的应用，正常退出并带连接参数重开一次。已有工作窗口保持，输入、退出拒绝、超时等情况会跳过。
3. 程序复制到个人“应用程序”，配色保存在用户“资源库”的 Application Support/CodexProjectColors 中。安装成功后可关闭管理窗口，原解压包不再作为运行依赖。
4. 下次用原官方图标打开，启动时可能短暂重开一次。初始化完成前先等待，不必打开配色管理窗口。若在启动过程中操作，助手会保留工作而跳过重开；可保存工作后完全退出，再从官方图标正常打开重试。
5. 首次安装默认开启，识别到本地项目后自动随机分配一套六色方案并保存。无需先点击随机按钮；点击头像上方调色盘可改颜色或重新随机。已有配色迁移时保留，不重新随机；后续用户主动清空也不会被自动补回。

1.0 已补充开机恢复与登录助手的启动顺序处理：开机两分钟内，启动不超过三十秒且未操作的前台实例可补接入；其他已使用窗口保持。

头像上方的窄卡片有两个按钮：额度按钮打开账号额度、重置时间及卡券到期详情；调色盘按钮打开项目配色。在配色面板底部可独立关闭或重新开启“显示账号额度”，不影响项目颜色；设置在重连后保留。三天内到期的卡会显示红色提醒。

多个主窗口时，通过管理程序“更多操作 → 选择连接窗口”选择一个。选择新的官方应用路径也位于更多操作。

## 停用与卸载

点击“停用自动配色”停止后台并注销启动助手。之后可用“启用自动配色”恢复。

“更多操作 → 卸载自动配色”停止后台，移除本工具的登录配置和已安装程序，配色及备份保留。关闭管理窗口只关闭界面，后台继续运行。

不会替换官方图标、修改官方程序包或强制结束用户工作窗口。停止配色不会关闭当前官方客户端的调试端口；自行完全退出，再从原图标正常打开即可结束这次调试启动。

## 发布状态
