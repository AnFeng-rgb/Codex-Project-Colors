## 本次更新

- 在最近列表中，为已确认的普通 Chat 显示常驻灰色圆角小竖条，方便与 Work／Codex 对话区分。
- 改善仅依赖启动快照造成的覆盖不足；列表中可见且类型信息可靠的较早聊天也能显示标记。

## 兼容与识别范围

本版面向 Apple Silicon Mac 上受支持的 ChatGPT／Codex 桌面界面，依据客户端提供的类型信息识别当前已加载到最近列表的普通 Chat。未知或冲突类型保持不标记；归档或尚未加载的会话在进入侧栏后再判断。当前客户端的内部结构可能随版本改变，届时需要适配。此功能不按会话创建设备或网站推断来源，也不承诺覆盖全部历史记录。

程序采用本地 ad-hoc 完整性签名，尚未完成 Developer ID 签名和 Apple 公证；安装方法见包内说明。

已有项目配色及额度设置保留。本项目是社区辅助工具，不代表 OpenAI 官方发布。
