## 1.0 新增余额 / 额度功能

发布标签：**v1.0.0-balance-icon**。这里的余额指账号剩余额度；本版本显示五小时和周额度，不是现金余额或月额度。

普通使用者请下载 **CodexProjectColors-v1.0.0-balance-icon-macos-arm64.zip**，无需自行编译或安装 Node。解压后双击程序，点击“安装并启用”；以后继续使用原官方图标。源码使用 `CodexProjectColors-v1.0.0-balance-icon-source.zip` 或 GitHub 的 Source code 下载。

### 本次更新

- 新增剩余额度圆环、明确的重置日期时间、可用重置卡张数和到期详情，自动更新真实数据。
- 配色与额度位于同一张窄侧栏卡片，保留两个独立按钮，各自打开对应面板。
- 三天内到期的卡优先显示红色“即将到期”，收起后有独立红色“!”与数量提示，圆环颜色不受临期提醒影响。
- 新增“显示账号额度”独立开关，关闭后调色盘仍可用，重连后保留选择。
- 两个面板最多 200px，卡券状态保持单行，支持深浅模式与窄窗口。
- 修复开机时官方应用先于登录助手启动的观察顺序，保留未操作、前台、单实例、端口及身份检查；正在使用的工作窗口保持。
- 保留默认六色、项目宽月牙、选中对话同色文字与圆角竖条、色轮、随机配色及撤销、原子保存与备份。

### 验证与兼容

65 项 Node 检查、38 项隔离浏览器界面检查和本机开关保存 / 后台重连检查通过。程序包与独立源码包均检查后上传，SHA256SUMS.txt 对应上述两个 ZIP。

当前程序包针对 Apple Silicon Mac。本机验证基准为 macOS 27.0、ChatGPT 26.1007.30912 的 Codex 界面，首阶段管理一个指定窗口中的本地项目。Intel、Windows 和其他机器未验收。原官方图标普通冷启动已实测；新增开机恢复策略的整机重启专项实测仍待完成。

程序有 ad hoc 完整性签名，**尚未完成 Developer ID 签名和 Apple 公证**，首次下载打开可能被 macOS 拦截。安装和允许打开的方法见包内 INSTALL.md，无需关闭系统安全保护。
